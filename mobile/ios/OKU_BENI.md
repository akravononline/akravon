# AKRAVON iOS

Derleme: GitHub Actions (`.github/workflows/ios.yml`) macOS makinesinde imzasiz `AKRAVON.ipa` uretir.
Yukleme (ucretsiz): Windows'ta Sideloadly ile ucretsiz Apple ID kullanarak telefona imzala + yukle (7 gun gecerli).

Oyun dosyalari IPA icinde DEGIL. Uygulama Belgeler klasorunu okur; Dosyalar uygulamasi (AKRAVON klasoru) veya Finder > Dosya Paylasimi ile
Android'deki `files/` icerigini (mobile/*.zip, lib, config, data, fonts, bgm ...) oraya kopyalayin.
Ilk acilista gunluk: Xcode > Devices > Console veya `idevicesyslog`.
